# Security

neontide only draws above the Claude Code prompt and saves its own place in the story. It never reads or
writes your files, runs commands, uses the network or calls the model.

If you still find a security problem, **please don't post it in a public issue.** Report it privately:
open the repo's **Security** tab and click **Report a vulnerability**
([direct link](https://github.com/kumar-w0rkspace/neontide/security/advisories/new)).
Only the maintainer sees it. I'll reply there, fix it, and credit you if you like.

Only the latest version is supported. To get it, see **Install** in the [README](README.md).
